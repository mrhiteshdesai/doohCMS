# Naming Standards

## Files
- kebab-case for files and folders
- PascalCase for React/Flutter components

## API
- REST plural nouns: `/users`, `/cameras`
- camelCase JSON fields

## Database
- snake_case table and column names (Prisma @map where needed)

## Modules
- IDs: M01, M02, ...
- User stories: US-001 [M01]
